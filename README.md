# 今日穿搭 · 私人衣橱搭配助手

一个移动端优先的本地衣橱搭配工具。用户可以上传自己的衣物照片、补充品类/颜色/季节/风格标签，再结合手动天气或浏览器定位天气生成搭配建议。

## 主要功能

- 批量上传衣物照片，并在浏览器内压缩
- 衣物标签编辑、筛选和搜索
- 手动天气输入，或通过浏览器定位调用 Open-Meteo 实时天气
- 根据温度、季节、保暖度、风格和场合推荐搭配
- 一键换一套、收藏搭配
- PWA 支持，可添加到手机桌面
- 本地优先隐私：照片和记录存储在 IndexedDB/localStorage，不上传到公共服务器

## 本地运行

这是一个无构建步骤的静态站点。进入 `dist` 后启动任意静态服务器即可：

```bash
python -m http.server 4173
```

打开 `http://localhost:4173`。

## 目录

- `dist/index.html`：页面结构
- `dist/styles.css`：响应式样式
- `dist/app.js`：衣橱、天气与搭配逻辑
- `dist/manifest.webmanifest`、`dist/sw.js`：PWA 配置

## 数据说明

站点是公开可访问的，但每位用户上传的衣物图片和搭配数据默认只保存在自己的浏览器中。清理浏览器站点数据会同时清空个人衣橱。
